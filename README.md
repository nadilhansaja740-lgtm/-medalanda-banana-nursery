🌿 About the Project

Medalanda Banana Nursery Management System is a modern digital platform developed to manage banana plant nursery operations efficiently.

The system helps manage plant batches, potting records, propagator periods, nursery stock, sales, fertilizers, chemicals, and staff information in one place.

Designed for easy use on mobile phones, tablets, and computers.

🍌 Main Features

Feature| Description
📊 Dashboard| Live nursery overview and stock summary
🌱 Batch Management| Manage Ambun, Kolikuttu, Ambul and other varieties
🪴 Potting Records| Record potting dates and initial plant counts
⏳ Propagator Tracking| Automatic 14-day propagator period
📦 Stock Management| Add, remove and correct batch stock
🧾 Sales Management| Record sales and automatically reduce stock
🧪 Fertilizer Records| Track fertilizer applications such as 20:20:20
🧴 Chemical Records| Track Mancozeb and other chemical applications
👥 Team Management| Manage owner, teacher, developer and staff details
📄 Reports| Print reports and export batch data to CSV

🚀 Installation & Deployment

1. Download or clone this repository.
2. Configure your Firebase Web App settings in "firebase-config.js".
3. Enable Firebase Email/Password Authentication.
4. Create an administrator account.
5. Apply the secure Firebase Database Rules.
6. Upload the project to GitHub.
7. Connect the GitHub repository to Netlify.
8. Deploy the website.

See the setup guide in "README_SI.md".
